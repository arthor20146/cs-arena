# CS Arena

FPS tactique gratuit, terroristes contre anti-terroristes : bombe, économie, manches, pass de combat et maîtrise des armes.

- **Site de téléchargement** : la page `index.html` de ce dépôt, publiée avec GitHub Pages.
- **Télécharger le jeu (Windows)** : onglet *Releases*, fichier `CSArena-Windows.zip`.
- **Jouer dans le navigateur** : https://cs-arene.onrender.com

Non affilié à Valve ni à Counter-Strike.
